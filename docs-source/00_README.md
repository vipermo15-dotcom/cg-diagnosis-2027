# 2027 컴퓨터그래픽디자인과 지원자 자기진단 웹서비스

학과 홈페이지에서 지원자가 자기진단을 통해 자신의 상황·교육목표·직무·AI 관심을 확인하고 주간/야간 및 관련 교육과정을 비교한 뒤 상담·지원으로 연결되는 웹서비스.

## 핵심 원칙
- 과정 선택의 폭 확대
- 컴그를 무조건 추천하지 않고 비교정보 제공
- 연령 자체를 추천근거로 사용하지 않음
- 진단은 적성/합격 판정이 아니라 교육과정 탐색용
- YAML → Engine → UI → Supabase → 관리자 구조

## 포함
STEP 1~21 기획/개발 문서 + 개발용 YAML + Supabase/Claude Code 명세
