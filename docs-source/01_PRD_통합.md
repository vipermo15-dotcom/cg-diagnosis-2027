# 2027 컴퓨터그래픽디자인과 지원자 자기진단 웹서비스 통합 PRD v1.0

## 목적
지원자가 3~5분 자기진단을 수행하고 현재상황·교육목표·경력·희망직무·AI·포트폴리오 방향을 확인한 뒤 주간/야간 및 관련 과정을 비교하도록 한다.

## 핵심 대상
취업준비, 재직자, 직무전환, 경력단절/재진입, 중장년 제2직업, 은퇴예정/은퇴후, 프리랜서, 창업, AI 신기술, 진로미정.

## 핵심 구조
홈페이지 → 자기진단 → Q01~Q40 → 분석 → 결과 → 직무방향 → 주간/야간 비교 → 관련 과정 비교 → 학습로드맵 → 상담/지원.

## 5대 직무트랙
1. BX·브랜드
2. 광고·콘텐츠
3. 편집·인쇄
4. 패키지·굿즈·커머스
5. 디지털·AI 비주얼

## 야간 4대 진로트랙
AI 디자이너 / 캐릭터 디자이너 / 콘텐츠 크리에이터 / AI 창업

## 결과 원칙
적성점수·합격/불합격·과정 1위 표시 금지. “현재 응답과 연결되는 교육 방향”으로 표현.
